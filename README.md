
# Smart Clock

A responsive digital clock website built using HTML, CSS and JavaScript.

## Features

- Live Digital Clock
- Automatic Date and Day
- 12-Hour and 24-Hour Format
- Stopwatch
- Countdown Timer
- Dark and Light Mode
- World Clock with Four Cities
- Responsive Dashboard Layout

## Technologies Used

- HTML
- CSS
- JavaScript

## Live Website

[Visit My Smart Clock](https://courageous-bublanina-507336.netlify.app/)

## Project Purpose

This project was created to practice frontend web development and improve my skills in HTML, CSS and JavaScript.
